4. Permitted Security Checks Performed

The following automated passive inspection checks were conducted against the target endpoint:

  1. HTTPS Availability & Port 80 Redirection: Validates port 443 connectivity and verifies whether port 80 enforces automatic HTTP 301 redirection to HTTPS.
  2. TLS Certificate & Cryptography: Inspects certificate validity, trust chain, expiration window, negotiated protocol (TLS 1.2+), and cipher suite.
  3. HTTP Security Headers: Audits Content-Security-Policy (CSP), Strict-Transport-Security (HSTS), X-Content-Type-Options, Frame Protection (X-Frame-Options or CSP frame-ancestors), Referrer-Policy, and Permissions-Policy.
  4. Cookie Security Attributes: Inspects Set-Cookie headers for Secure, HttpOnly, and SameSite attributes (cookie values are discarded and never logged).
  5. Information Exposure: Evaluates Server, X-Powered-By, and framework headers for operating system and version banner disclosure.
  6. HTTP Redirect Behavior: Traces the redirect chain to identify security downgrades (HTTPS to HTTP) or excessive hops.
  7. Mixed Content References: Scans static HTML tags for unencrypted HTTP resource references within HTTPS pages.
