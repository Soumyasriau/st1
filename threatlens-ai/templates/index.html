The 7-Stage Threat Modeling Workflow

How ThreatLens AI turns observable website configurations into prioritized cybersecurity defenses

01

Target Identification

User supplies a target website URL. Strict input normalization and anti-SSRF address filters validate the host.

02

Passive Observation

Executes safe HTTP/TLS requests without brute force or payloads, reading public headers and certificates.

03

Weakness Identification

Evaluates transport security, TLS validity, cookie attributes, mixed content, and 6 core security headers.

04

STRIDE Scenario Mapping

Maps each weakness to STRIDE threat categories (Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation of Privilege).

05

Risk Estimation

Calculates transparent Risk Score = Likelihood (1–5) × Impact (1–5), classified into Low, Medium, High, or Critical.

06

Mitigation Guidance

Generates tailored remediation recommendations and step-by-step verification checklists for developers.

07

Executive Reporting

Stores results in SQLite and provides downloadable HTML, JSON, and PDF reports for stakeholder review.

Security Engine Highlights

Engineered specifically for transparent, ethical, and defensive cybersecurity analysis

🛡️

SSRF-Immune Architecture

Pre-resolves hostnames against RFC 1918 private subnets, loopbacks (127.0.0.1, ::1), link-local ranges, and cloud metadata endpoints (169.254.169.254). Revalidates every redirect hop.

🧩

STRIDE Threat Matrix

Classifies weaknesses into the industry-standard Microsoft STRIDE framework. Distinguishes hypothetical attack vectors from confirmed software vulnerabilities.

🎚️

Interactive Risk Tuner

Adjust Likelihood and Impact values directly on the results screen. The engine dynamically recalculates risk scores and updates the severity matrix in real-time.

📑

Multi-Format Reporting

Generate formal executive reports formatted for client presentations, printable browser views, direct ReportLab PDF export, and machine-readable JSON dumps.
